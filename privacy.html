Privacy on this website

This page covers rosegardengames.com itself. Each game has its own privacy policy, linked from the game's entry on the front page.

What this website collects

Nothing. It sets no cookies and uses no analytics, trackers, ads or fonts from other sites.

Hosting

The website is served by GitHub Pages. Like any web host, GitHub receives your IP address when your browser fetches a page, and may log it for security. How GitHub handles that is described in the GitHub General Privacy Statement. We never see those logs.

Email

If you write to us, we use your address and message only to answer you. We do not add you to any list, and we delete the correspondence if you ask.
